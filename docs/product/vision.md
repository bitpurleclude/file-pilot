# File-Pilot 产品愿景：个人文件层级的治理层

版本：v1.0（2026-10-10）
状态：Direction（方向性文档，未承诺发布版本）

## 一句话定位

File-Pilot 从「AI 帮你分类文件」升级为「**工具治理你亲手设计的轻量层级**」——用户只造结构（登记册），工具管其余一切（出生查重、路由、lint、退役、可回滚重排）。

这个定位由四十年研究与实践（详见 `docs/product/domain-research.md`）交叉验证：

- 纯 AI 自动整理（WinFS 一脉、新世代 AI organizer）从未形成闭环；
- 纯人工方法论（PARA / Johnny.Decimal）没有软件强制执行，靠自觉必然烂掉；
- **治理闭环**（登记册 + 出生查重 + 生长协议 + AI 路由 + 会话回滚）的每一块配料市面上都有人单独做过，组合态在主流产品中空缺。

## 北极星指标

1. **找得回**（KFTF）：任何文件在整理半年后，仍能通过工具回答「它去哪了」。整齐是手段，找得回是目的。
2. **人力决策预算**：每文件人工决策 ≤ 0.1 次（十个文件最多问一次人）。归档制度性失败的根源是「成本即时、收益遥远」（Whittaker & Sidner, 1996），工具必须把人工确认压缩到批量、低频、一分钟级。

## 六条设计原则

每条格式：来源研究/实践 → 原则 → 对产品的具体含义。

### 1. 找得回优先于整齐

来源：KFTF 项目（William Jones, UW）；Whittaker 系列。
原则：一切组织手段用「半年后还能找到吗」评分。
含义：会话记录（sessions 表）是现成的溯源索引——提供「文件去哪了」查询入口；自动入位允许出错但必须打「未确认」标记。**错而可寻 > 乱而不见**。

### 2. 人力决策是稀缺资源

来源：Whittaker & Sidner《Email Overload》(CHI 1996)——归档失败机制：文件夹增殖、过早归档、检索失败。
原则：归档成本必须趋近零；人工决策批量、低频。
含义：置信度分流（高置信自动入位+标记，低置信寄存而非逼问）；每周自动报告（「新增 37，自动入位 29，8 个待确认」）；吸取「过早归档」教训——信号弱时先寄存，攒够上下文再问。

### 3. 结构归用户造，治理归工具管

来源：Bergman 主观属性论（文件夹编码搜索无法匹配的主观线索）+ WinFS 之死。
原则：AI 生成深层分类法死路一条；纯靠用户自觉维护结构也死路一条。中间态是：用户造轻结构（≤3 层、编号槽位），工具管治理。
含义：登记册由用户确认；层级永远真实文件夹（不做数据库黑盒，保住可移植性与 Everything 兼容）；工具职责=出生查重、命名 lint、退役归档、批量重排。

### 4. 确定性走规则，模糊才走 LLM

来源：Hazel（规则引擎）数十年验证的分工。
原则：正则能干的烧 token 是浪费；LLM 只处理规则空隙。
含义：现有 `规则 → LLM → 本地兜底` 管线形态正确，扩展方向是把规则条件对接登记册坐标（「源目录在某项目槽下 → 直接归入」）。登记册越厚、规则命中率越高、LLM 成本越低——用户每次「教」都沉淀为免费路径。

### 5. 交叉用引用解决，不用复制

来源：DEVONthink Replicate；Zettelkasten 链接哲学。
原则：树的数学性质决定它表达不了交叉；交叉需求由元数据层满足，字节不动。
含义：逻辑视图/标签层（实现选型：NTFS junction vs 索引视图，见 `governance-design.md`）；相似推荐（See Also 语义）作为 LLM 链路的后续扩展。

### 6. 搬迁必须可回滚

来源：PARA 的移动语义；本项目 sessions + rollback 既有能力。
原则：没有人敢手工重排层级，因为剪切粘贴没有撤销。
含义：任何批量重排（合并 `video`/`vedio`、整域归档）都是一批带完整记录、可一键回滚的会话。**这是本项目相对全部竞品已有的独占能力。**

## 反目标（明确不做）

- **不做语义文件系统**：不取代文件夹，不做元数据查询式黑盒（WinFS 四十年墓碑）。
- **不做全自动整理**：人不确认不落锤；AI 只提议与执行，结构权在用户。
- **不要求预先完整分类**：Inbox 容纳不可预知，领域按需认领空号（生长协议）。
- **不做纯搜索工具**：空间结构是人脑检索的拐杖（Bergman），搜索只是补位。

## 成功标准（产品级）

1. 对真实乱盘（如开发者的 D 盘：`video/vedio` 拼写孪生、`公务员/公务员考试` 语义交叉、四处下载目录）能自动产出重叠检测报告，并给出可回滚的合并方案。
2. 连续使用一个月后，周报显示人工决策率 ≤ 0.1 次/文件。
3. 任意时刻执行「文件去哪了」查询，对工具经手的文件 100% 可回答。
