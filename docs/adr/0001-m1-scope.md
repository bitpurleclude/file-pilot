# ADR-0001: M1 范围收敛策略

## 状态

Accepted

## 背景

`PLAN.md` 的长期目标覆盖 M1~M4。当前仓库从规划向工程转型，需要先形成可运行的 M1 全链路基线。

## 决策

本次 M1 以“可运行、可测试、可发布 beta”为目标，优先实现：

1. 基础 UI 拖拽入口
2. 分析/分类/规划/Dry-run/回滚最小闭环
3. 白名单与日志导出
4. 测试与发布链路

其余能力（更新器完整实现、Everything 适配、复杂模板治理）延后到下一迭代。

## 影响

- 优点：快速形成稳定可验证基线。
- 代价：部分高级能力以后续迭代补齐。
